### 🛡️ About Me

I am a **Cybersecurity Engineer** specializing in **Defensive Security (Blue Team), Digital Forensics & Incident Response (DFIR), and System Hardening**. My expertise lies in investigating threat vectors, analyzing memory dumps, hardening enterprise Linux environments, and developing custom security automation scripts in Python and Bash.

- 🔭 **Focus Areas**: Threat Detection, Active Directory Security, Memory Forensics (Volatility 3), Network Traffic Analysis (Wireshark/Nmap), & Security Automation.
- 💻 **Portfolio & Knowledge Base**: [aimadulislam.dpdns.org](https://aimadulislam.dpdns.org) — featuring in-depth labs, research writeups, and security cheatsheets.
- 🎯 **Career Goal**: Contributing to Security Operations Centers (SOC) and Incident Response teams to protect critical infrastructure.
